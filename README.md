# EW4-mod_editor

欧陆战争 4 Rewrite 批量 Mod 编辑器，当前版本 **0.2.0**（2026-10-24）。

以用户提供的 Vue 3 / TypeScript / Canvas 编辑器为底座，增加独立的本地作者服务。复用地图、缩放、图层与原版面板；Rewrite 读写、将领转换和 Mod 校验使用所选 Rewrite 源码快照中的实现。

## 0.2.0 更新

相对仓库的 `0.1.0` 初始 Rewrite 工作台，本版增加：

- **Mod 导入合并**：预览 `.ew4mod` 文件差异，选择替换或合并；冲突可暂停、保留当前或覆盖。保存来源包哈希、文件来源和剧本清单，支持历史及重启恢复。
- **Rewrite 扩展技能绑定**：批量替换或移除技能槽，设置等级，并排查看原始技能与最终有效技能。原版四个技能字段与 Rewrite 动态技能列表分开处理，数量限制见下文。
- **Rewrite 部队删除界面**：列表多选或地图选区、删除目标及完整槽位迁移预览、引用保护、撤销和重做。
- **部队追加部署后端**：完成 BTL writer、作者 API、参数校验及标准包开局/存档恢复验证；**网页部署入口尚未接入**。
- **资源适配与兼容性修复**：头像、城市/国家名称、manifest 和图集检查；原版新增/删除/粘贴事务、空槽和事件引用修复。
- **专项验收**：导入、技能、资源、结构操作、桌面/手机浏览器，以及真实 Rewrite 开局和存档恢复测试。

完整版本记录见 [CHANGELOG.md](CHANGELOG.md)。`0.1.0` 已有将领原版字段批改、多剧本规则、CSV、配方、历史和标准导出，这些能力继续保留。

## 启动

需要 Node.js 22+、npm、.NET SDK 10，以及带完整 `rewrite/data` 的 [ew4-rewrite](https://github.com/aztksilence111/ew4-rewrite) 工作副本。游戏资源与 Rewrite 源码快照不随本仓库分发。

默认两项目并列放置：

```text
game/
  o4mod/rewrite/
  mod-editor/
```

```powershell
npm ci
npm run setup
npm run dev
```

打开 <http://127.0.0.1:5174>。API 监听 `127.0.0.1:5184`。后续启动只需 `npm run dev`，该命令会先构建 bridge，再启动 UI 和 API；端口已被本项目使用时可直接访问现有服务。非默认源码位置的首次 setup 命令：

```powershell
npm run setup -- C:/path/to/ew4-rewrite/rewrite
```

`setup` 在 `.local/rewrite` 固定必要源码及资源，生成逐文件 SHA-256 基线。它读取当前工作副本，包括尚未提交的源码；基线文件哈希才是本次作者工程的准确输入，Git 提交号只作来源提示。该目录不进入 Git。若已经建立基线，脚本拒绝覆盖；切换引擎版本请用新的编辑器检出目录并先导出作者工程。

## 当前功能

- 将领表格：国家/ID/名称筛选、多选，能力、军衔、爵位、星级、原版技能和初始装备字段批改；另提供 Rewrite 注册技能绑定编辑。
- 国家资源、部队、城市、领土和手工辖区批量修改。同一规则可用于多份剧本，国家以真实 ID 匹配。
- 地图点选和双角点矩形选择，选择高亮、辖区颜色层；带选区的配方限定同一底图。
- 规则顺序执行，差异预览、整批提交、撤销/重做、旧预览拒绝、任务 ID 重试去重。
- CSV 往返、配方 JSON、作者工程 `.ew4author` 保存和恢复，本地草稿持久化。
- 将领 XML → Rewrite 转换器 → `legacy/catalog.json` → 源哈希更新 → 运行时校验。
- 将领头像改名会同步 manifest 图集映射（目录型高清头像会复制实际 PNG）；城市 XML、字符串表会生成 `frontend/city-names.json`、manifest 和国家名称资源，恢复/预览/导出会检查图集坐标、头像、首都、国家和城市引用。
- 通过 Rewrite `ModStore.Seal` / `Validate` / `Import` / `Export` 输出 `.ew4mod`。导出使用独立暂存和安装目录。
- 导入 `.ew4mod` 并预览文件差异，支持替换或合并、冲突暂停/保留/覆盖；保存来源哈希与剧本清单，支持整批撤销和重做。
- 原编辑器保留在“原版示例”入口；Rewrite 工程与原版草稿、示例资源分开。

作者工程保存在 `.local/author.json`。最多保留 30 批撤销历史，切换页面后仍可恢复。导出的 `.ew4author` 绑定精确资源基线，恢复前会校验。当前是单个活动作者工程，多个工程可以分别导出保存。

## 将领批量修改

| 类别 | 当前支持 |
| --- | --- |
| 等级数值 | 军衔、爵位、星级 |
| 能力 | 步兵、骑兵、炮兵、海军、要塞、经济、移动、训练 |
| 原版字段 | `skill1` 至 `skill4`、初始装备 `item1` 和 `item2` |
| Rewrite 扩展技能 | 注册技能绑定、槽位替换/移除、技能等级；原始与最终有效技能对照 |
| 数值运算 | 赋值、增加、倍率；四舍五入、向下或向上取整；越界拒绝 |
| 文件交互 | CSV 导入/导出、配方 JSON 保存/加载 |

常用流程：在“将领”面板筛选并勾选目标，选择字段、运算和值，点击“加入批处理”，再到“批处理”检查规则、预览差异并应用。未勾选时，规则使用当前全部筛选结果；已勾选时，只使用勾选项与当前筛选结果的交集。

**技能数量说明：**原版 XML 只有四个技能字段；Rewrite 扩展技能使用动态列表，当前所选引擎源码没有固定数量上限。**本版编辑器 UI 和作者 API 仍限制可编辑槽位为 `0..15`（16 个）**，这是尚未解除的编辑器限制，不是 Rewrite 引擎上限。扩展技能绑定通过绑定控件编辑，不通过原版四技能 CSV 字段编辑。

## 工程与内容包

| 文件 | 用途 |
| --- | --- |
| `.ew4author` | 保存/恢复作者工程，绑定精确资源基线 |
| `.ew4mod` | 导入内容包，或通过 Rewrite 标准流程校验和导出 |
| 配方 JSON | 保存可重复执行的批处理规则 |
| 将领 CSV | 批量交换受支持的原版将领字段 |

导入 `.ew4mod` 后先预览差异，再选择替换或合并及冲突策略，确认后应用。导出使用独立暂存和安装目录，不自动启用导出的 Mod。

## 格式与事务

BTL 常规字段修改保持记录数和坐标不变，保留记录原始字节及未知字段。bridge 已支持明确槽位的部队结构删除，实际缩短 armies section、更新计数，并在预览返回每条规则的旧槽位到新槽位映射。Rewrite 的“部队”面板可按当前槽位多选，或选入地图选区部队，预览删除目标和完整迁移表后应用；取消不落盘，应用及历史操作后刷新场景和选择。已知 JURI/CNTR/VICT 扩展重新绑定主体哈希，VICT 中存活部队目标同步迁移，再由 Rewrite 读取及开局验证。引用待删除部队的胜负条件、未知扩展，以及带外部胜负/剧情事件或注册脚本的工程会阻止结构删除。导出前会建立部队、建筑、商店、酒馆、火焰和事件的反向引用，拒绝重复 cell 和已知世界地图下超出剧本矩形的 cell，缺失事件引用保留为警告。未知可选块允许原样保存，但会阻止修改；未知必需块由 Rewrite 拒绝。原版编辑器的扩展 BTL 写出旁路也已阻止。

首次建立 JURI 时，先固定引擎当前的有效自动辖区，再应用选区修改，预览中会列出此初始化。已有 JURI 中的 `-1` 不会被自动补齐。领土和辖区是两种独立规则。

原版示例的部队/建筑新增、删除和粘贴通过副本事务更新。建筑类型 `255` 仍可能带工事或桥梁，不作为空槽；只有负 cell 槽位可复用。删除主体保留同格独立商店、酒馆、火焰和另一主体的事件绑定，事件效果坐标保持原样。实际 Rewrite 开局/存档恢复已确认：负 cell 站点可接受，负 cell 部队、商店、酒馆和火焰会被拒绝。原版 UI 的部队删除仍作为草稿操作，恢复或复用所有部队空槽后才能导出；序列化出口继续阻止不兼容记录。bridge 的结构删除通过独立作者事务执行，不放宽这一闸门。

事件引用按有符号字节解释：`0..127` 是有效 ID（包含 `0`），`128..255` 表示无绑定。原始剧本也可能含未解析的有效 ID，检查会报告警告，与 Rewrite 的缺失引用行为一致。只有效果 `5` 消费事件 cell；商店/酒馆不要求同格存在站点。

预览验证受影响剧本的代表开局，将领改动会覆盖全部剧本。完整校验会逐个验证所有征服可玩国家。导出另做 Rewrite 的完整包与资源检查；校验失败不会发布新的工程修订。验证和导出可能需要几十秒。

CSV 第一行为字段名，包含 `schema`、`sourceHash` 和稳定 `id`。`name` / `country` 是锁定身份列。缺列或空单元格表示不修改；技能和装备的 `~clear` 明确写入 `-1`。重复 ID、重复/未知列、过期源哈希、非法数值均阻止整批提交。倍率取整有显式选项，越界拒绝，不自动截断。

## 检查

```powershell
npm test
npm run build
npm run build:bridge
npm run test:runtime
npm run test:structural
npm run test:deployment
npm run test:integration
npm run test:import
npm run test:skills
npm run test:resources
npm run test:browser:import
npm run test:browser:structural
node tests/browser.mjs
```

集成测试启动独立 `5190` API，测试作者状态和生成包均放在 `.local/tests`，不修改当前作者草稿。默认集成入口包含导入专项，也可用 `test:import` 单独运行。`test:runtime` 在已有 bridge 构建上调用 Rewrite 开局与存档恢复，再使用隔离 `5192` API 验证作者工程恢复的原子拒绝和标准包导出；输入与结果保存在 `.local/runtime-compatibility`。`test:browser:import` 自动启动 5175/5186 隔离服务、准备可缓存的合法内容包并执行双视口导入验收，结束后关闭服务；需保持测试端口空闲。普通 `browser.mjs` 需要开发服务已启动。浏览器默认使用本机 Microsoft Edge，截图、夹具与检查报告位于 `.local`。

`test:browser:structural` 使用 `test:structural` 生成的兼容性夹具和隔离 5175/5195 服务，覆盖桌面/手机删除、保护错误和历史恢复，再对两份实际下载包执行真实开局/存档恢复。它与 `test:browser:import` 共用 UI 测试端口，需串行执行；使用 `EW4_EDITOR_TEST_DLL` 时，两者和 C# harness 都读取指定构建。

`test:deployment` 验证 bridge 末尾追加部队的 writer/作者 API，使用已有结构夹具和隔离 5197/5198 服务，覆盖默认值、海陆/归属约束、混合批次、历史/重启、标准包导出及实际开局/存档恢复。已纳入集成入口；部署 UI 尚未接入。此路径保留已有单位 ID、独立商业/事件/辖区和原版导出闸门，不复用负 cell 草稿。

`test:integration` 按顺序运行主集成、导入、技能、资源、结构删除和追加部署专项。独立运行 `test:deployment` 或 `test:browser:structural` 前，需先运行 `test:structural` 生成兼容性夹具。`npm run build` 包含前端类型检查。

## 当前边界

这是规划的首轮可用基础，尚未完成全部 P1：网页表格粘贴、国家科技数组、部队部署 UI、建筑迁移及引用联动仍待实现。bridge 追加部署 writer/作者 API、Rewrite 部队结构删除 UI、扩展技能绑定编辑已接入，支持原定义与最终有效技能并排查看；头像、城市/国家名称、图集和 manifest 的资源适配已接入并有隔离专项验证。高级区域复制、事件与胜负编辑、地图变形、XLSX 和独立游戏预览界面也尚未接入。

解除编辑器对 Rewrite 扩展技能的 16 槽位限制仍待完成。

地图资源目前沿用附件的示例图集与名称数据；BTL/BIN 来自当前 Rewrite 工程，新增图集和游戏内视觉效果仍需隔离游戏验收，不能把地图示例外观视为游戏画面的精确预览。旧 `.ew4p` 只能在原版示例中使用，尚不能直接迁移为 Rewrite 作者工程。分包构建不再输出单 HTML，旧按钮会明确提示。

本地作者服务不提供任意路径写入或命令执行 API，只监听回环地址，检查 Host、Origin、JSON 类型及写请求标头。它不连接玩家服务、不写账户或存档、不自动启用导出的 Mod。桌面模拟开局不替代 Android 真机验收。
