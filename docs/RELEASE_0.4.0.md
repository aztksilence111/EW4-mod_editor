# EW4 Mod Editor 0.4.0

- 接入当前 R 版 API 3 Mod 接口。“内容编辑 → 扩展规则”支持空地分层、施工建筑、粮食收入、自定义将领能力、技能/光环、状态、装备效果与绑定；可编辑 JSON、Lua、PNG，先校验预览再应用，支持撤销/重做及完整 Mod 导入导出。
- 附带当前引擎的离线接口说明与 8 组官方示例。示例中的剧本、国家、格号需按作品调整。
- 东亚、日本、神罗等已配置地图无需现成 BTL，可直接创建全图空白剧本。日本 57939 格、神罗 52461 格，支持全图末端格号编辑。
- 新增导出文件检查：BTL、资源 ZIP、`.ew4mod`，覆盖结构、地图范围、引用、哈希和实际引擎开局，支持保存错误报告。
- 修复带桥城市图标，地图与辖区支持实际地名、搜索和定位。

下载 `windows-web.zip` 解压运行 `Start-Editor.cmd`，无需安装 Node 或 .NET。Android 下载 `arm64.apk`，要求 Android 8 或以上。

Android 包名保持 `org.ew4.modeditor`，versionCode 3；新资源基线使用独立目录并保留旧作者目录。旧 `.ew4author` 绑定原资源基线，不能直接覆盖新基线工程；Windows 请解压到新目录。发布包不含用户作者稿或游戏存档。

导出检查覆盖当前资源基线与开局，后续回合、视觉效果仍需试玩。空白剧本需要继续配置领土和部署。Android 尚未完成真机安装及系统文件窗口验收。
