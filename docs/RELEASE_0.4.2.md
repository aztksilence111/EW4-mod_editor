# EW4 Mod Editor 0.4.2

- 新增“内容编辑 → 兵种”：从模板复制独立兵种 ID，与原兵种共存；编辑属性、兵模与图卡模板、独立招募建筑/等级/费用及国家和剧本范围。
- 支持一次性开局增援部署、完整资源与实际开局校验、撤销/重做、工程恢复和 `.ew4mod` 导出。
- 同步 R 版 0.2.39 / API 3。游戏运行这些独立招募配置需要 R 版 0.2.39 或更新版本。
- 保留 0.4.1 的剧情编辑、扩展规则、原版将领、辖区及完整地图制作功能。

Windows 下载 `windows-web.zip`，解压至新目录运行 `Start-Editor.cmd`，无需 Node 或 .NET。Android 下载 `arm64.apk`，Android 8 或以上，包名 `org.ew4.modeditor`、versionCode 5，沿用旧签名。

新版 Android 使用独立目录 `r3-20261111`，保留旧基线作者目录；旧 `.ew4author` 与原基线绑定，不能直接恢复至不同基线。发布包不含用户作者稿、游戏存档或签名材料。尚未完成 Android 真机安装与系统文件窗口验收。
